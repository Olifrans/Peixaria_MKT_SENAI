# 🐟 Peixaria Suzano - Site Profissional Completo

Site estático de alta performance, otimizado para SEO Local, conversão via WhatsApp e 100% em conformidade com a LGPD.

## 🚀 Como Publicar
1. Crie uma pasta no seu computador e salve os 5 arquivos (`index.html`, `politica-privacidade.html`, `codigo-etica.html`, `style.css`, `script.js`) dentro dela.
2. Substitua todos os placeholders `[INSIRA SEU ... AQUI]` no `<head>` do `index.html` pelos seus IDs reais do Google e Meta.
3. Hospede gratuitamente no **Netlify**, **Vercel** ou **GitHub Pages** (basta arrastar a pasta para o Netlify Drop).

## ⚙️ Configuração de Marketing (Checklist)
- [ ] Substituir `[INSIRA SEU GA4 ID AQUI]` (Ex: `G-XXXXXXXXXX`).
- [ ] Substituir `[INSIRA SEU ADS ID AQUI]` (Ex: `AW-XXXXXXXXX`).
- [ ] Substituir `[INSIRA SEU GTM ID AQUI]` (Ex: `GTM-XXXXXXX`).
- [ ] Substituir `[INSIRA SEU META PIXEL ID AQUI]` (Ex: `1234567890`).
- [ ] Atualizar o link canônico e as meta tags Open Graph com o domínio real.

## 🧪 Testes Obrigatórios Pré-Lançamento
1. **Teste de UTM**: Acesse `seusite.com.br?utm_source=instagram&utm_campaign=stories`. Clique no botão do WhatsApp. A mensagem pré-preenchida deve dizer: *"Olá! Vim pelo site (instagram)..."*.
2. **Teste de Cookies**: Abra uma aba anônima. O banner de cookies deve aparecer. Clique em "Rejeitar". Abra o console do navegador (F12) e clique no WhatsApp. Deve aparecer a mensagem `[Track] Rastreamento bloqueado por LGPD`.
3. **Teste Mobile**: Verifique se a barra fixa "Ligar / WhatsApp" aparece apenas no celular e não sobrepõe o botão flutuante.

## 📈 Plano de Ação de Marketing Local (8 Semanas)
- **Semana 1-2**: Criar e otimizar o perfil do **Google Meu Negócio** com o mesmo endereço, telefone e link deste site. Subir 10 fotos reais da peixaria.
- **Semana 3-4**: Rodar campanha de **Google Ads (Rede de Pesquisa)** com palavras-chave: "peixaria delivery suzano", "camarão limpo suzano". Orçamento inicial: R$ 30/dia.
- **Semana 5-6**: Campanha de **Meta Ads (Instagram/Facebook)** com vídeo curto mostrando a limpeza do peixe e o corte grátis, direcionando para o WhatsApp com o pixel instalado.
- **Semana 7-8**: Parceria com 2 restaurantes locais do Centro de Suzano para fornecimento atacado (usar a aba de contato para cotação).

## 💡 Dicas Rápidas
- As imagens usam Unsplash com otimização (`?w=800&q=80`). Substitua pelas fotos reais do negócio para maior autenticidade.
- O número de WhatsApp já está formatado para o padrão internacional (`5511939592955`).
- O site possui modo escuro automático baseado na preferência salva do usuário.
